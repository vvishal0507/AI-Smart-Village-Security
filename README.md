# 🚨 AI Smart Village Security System

A privacy-first, offline AI-based security system designed for rural environments.

## 🔥 Overview

This project demonstrates a low-cost village security system using simulated data, AI-based risk detection, and a real-time dashboard.

## ⚙️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Real-time: Socket.IO
- AI Simulation: Python

## 🧠 How It Works

1. Python simulates activity data
2. AI logic calculates risk score
3. Backend processes event
4. Dashboard updates live

## ✨ Features

- Offline AI detection
- Privacy-first (no camera)
- Real-time monitoring
- Manual demo controls
- Event history tracking
